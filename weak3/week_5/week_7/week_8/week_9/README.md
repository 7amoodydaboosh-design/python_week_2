# Week 9 - Ticket Registration System

## Purpose

This program is used to register IT Helpdesk tickets for students. The user enters the student's information, issue, location, and priority. Then, the program assigns a technician based on the priority level and displays the ticket details.

## Files

- main.py
- ticket.py
- display.py

## How to Run

Open the project in VS Code, then open the terminal and run:

```bash
python main.py
```

After that, enter the required information when prompted.
