# Week 10 - Salary Calculator

## Files

- main.py
- employee.py
- salary.py
- report.py

## How to Run

```bash
python main.py
```

## Description

This program:

- Collects employee information
- Calculates gross salary
- Calculates EPF (11%)
- Calculates SOCSO (0.5%)
- Calculates net salary
- Displays a salary report
